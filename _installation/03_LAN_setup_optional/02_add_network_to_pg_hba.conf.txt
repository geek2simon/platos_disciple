STEP 02 - ADD THE LAN RULE TO pg_hba.conf
=========================================

This step is required only for LAN/multi-user installation.
Run Step 01 first.

1. Open LAN_Setup_Result.txt. It contains:
   - the exact pg_hba.conf location
   - the detected LAN subnet
   - the exact line to add

2. Open pg_hba.conf (usually at C:/Program Files/PostgreSQL/18/data/pg_hba.conf) as Administrator and add the generated line near the existing IPv4 host rules. It will look like this:

   host    pd_market_kb    kb_agent    192.168.1.0/24    scram-sha-256

   (Use the subnet generated by Step 01. Do not assume it is 192.168.1.0/24.)

3. Save pg_hba.conf.

4. In DBeaver, connected as postgres, run:

   SELECT pg_reload_conf();

5. Check for configuration errors:

   SELECT line_number, database, user_name, address, auth_method, error
   FROM pg_hba_file_rules
   WHERE 'pd_market_kb' = ANY(database)
      OR 'kb_agent' = ANY(user_name)
   ORDER BY line_number;

The new kb_agent row should appear and its error column should be NULL.
Then run Step 03 from a different LAN computer.
